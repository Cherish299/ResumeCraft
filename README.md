# ResumeCraft

> 面向大学生和求职新手的开源简历工作台。
>
> 先选模板、快速写出第一版，再用 AI 和本地体检把简历改得更适合投递。

ResumeCraft 是在原有 `resume-kit` 基础上持续打磨出的对外项目名称。

当前仓库仍保留原目录结构与部分内部命名，方便继续开发；但对外介绍、README 和产品定位统一使用 `ResumeCraft`。

## 这是什么

ResumeCraft 不是一个复杂的 SaaS，也不是只会换皮肤的简历模板站。

它更像一个轻量、好上手的本地简历工作台，适合：

- 第一次写简历的大学生
- 参加春招 / 秋招的应届生
- 想快速做出一份可投递简历的人
- 想在本地保存数据，不依赖在线平台的人

核心思路很简单：

1. 先用模板和示例把简历写出来
2. 再用体检和 AI 把内容改得更像简历
3. 最后导出 PDF、Markdown 或单文件备份

## 你可以怎么用

### 1. 普通用户：直接打开网页版或单文件版

| 文件 | 说明 |
| --- | --- |
| `index.html` | 适合 GitHub Pages 的公开入口页，普通用户打开链接后可直接进入网页版 |
| `dist/resume-workbench.html` | 推荐使用的单文件成品，双击即可打开 |
| `app/index.html` | 源码版页面，也可直接在浏览器中打开 |

> 数据默认保存在浏览器本地 `localStorage`，关闭页面不会丢。

如果你准备把它发给不会 Git、不会 DSH 的同学，推荐两种方式：

- 直接部署 GitHub Pages，让用户点开链接就能用
- 或把 `dist/resume-workbench.html` 发给对方，双击即可打开

### 2. 作为 DSH Web 插件使用

仓库包含一个可选的 DSH 插件包装层，打开后会在侧边栏底部出现入口按钮，点击即可打开全屏简历工作台。

插件说明见：`dsh-plugin/README.md`

## 核心功能

### 模板和示例

- 内置多种岗位模板：技术、后端、前端、数据、AI、产品、运营、市场、设计、职能类
- 可一键填入岗位示例，适合小白先改出第一版
- 模板会影响关键词、板块顺序、示例内容和 AI 改写上下文

### 结构化编辑

- 基本信息、求职意向、教育背景、实习、项目、校园经历、科研、奖项、技能、自我评价等分区编辑
- 左侧表单 + 右侧实时 A4 预览
- 支持板块隐藏 / 显示 / 调整顺序

### 一页简历和多版本

- 支持详细版、通用投递版、互联网 JD 版
- 支持一键压缩到一页
- 适合“先保留完整版，再生成更短投递版”的使用方式

### 本地简历体检

- 本地规则引擎打分
- 检查硬伤、量化结果、表达、关键词匹配、完整度
- 会直接提示哪里该改，不只是给一个分数

### AI 优化（可选）

可选接入 DeepSeek API，适合在写完第一版后继续优化：

- 看看哪里最影响投递
- 改成更适合投递的版本
- 把某段经历写得更像简历

设计原则：

- API Key 只保存在本地
- 不编造事实、数字、头衔、职责
- 输出尽量短，方便直接复制进简历
- 有 JD 时按 JD 调整重点，没有 JD 时做通用优化

### 备份和导出

- 导出 PDF
- 导出 Markdown
- 导出 JSON
- 导出单文件 HTML 备份

## 为什么适合求职小白

很多人第一次写简历时，卡住的不是排版，而是：

- 不知道该写什么
- 不知道项目经历怎么写得像简历
- 不知道哪些内容最影响投递
- 不知道怎么压到一页

ResumeCraft 主要解决的就是这些问题：

- 先给你模板和示例，降低起步难度
- 再用规则体检和 AI 帮你把内容改得更清楚
- 不要求你先理解复杂术语和工作流

## 项目定位

ResumeCraft 借鉴了开源社区里成熟的简历优化思路，尤其是：

- 先诊断，再改写
- 缺事实时先提醒补充，不乱编
- 强调动作、结果、量化和岗位匹配

但产品形态保持轻量，重点仍然是：

- 好用
- 易用
- 本地优先
- 对大学生友好
